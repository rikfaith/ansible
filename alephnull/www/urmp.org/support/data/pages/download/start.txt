urmp is currently in **beta** testing and development is **not** yet feature complete.

urmp opens all .mp3 files read-only and write only to files under ~/.urmp, or to the directoy specified using the -c or --config options.  However, this is **untested** software and should not be used except by beta testers.

===== Using git the first time =====

  git clone git://git.urmp.org/urmp
  cd urmp
  git clone git://git.urmp.org/ur

===== Using git to get updates =====

  git pull
  (cd ur; git pull)
