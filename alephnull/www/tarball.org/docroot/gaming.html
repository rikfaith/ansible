Suggested

There are two key changes in the suggested column:
  • The reviews suggest that SLI provides only about 10-30% improved performance, so I've suggested just getting one GPU. Multiple GPUs with SLI:
    • aren't cost effective (better to get a faster CPU or more memory),
    • runs hot (about 200W per board), and
    • limits upgrades (instead of replacing 1 GPU, you'll be tossing out 3).
  • 6-core CPU instead of 8-core, but with a faster clock rate, since any software is hard to parallelize for multi-core CPUs, and games are no exception (maybe in 5 years it'll be better?).
Dell has an option with a 6-core i7-5820k @3.3GHz, 32GB of RAM, and one GPU that is $3200 with the 256GB/4TB storage option (only about $200 more than the build-it-yourself price estimate -- and maybe a better deal with the $160 rewards Dell is offering, plus the Dell waranty).

Consider

The Haswell-E is an "enthusiast" chip, and is probably priced higher than other Haswell chips. The Haswell-E uses the LGA 2011-v3 socket, can use DDR4 memory, and uses a newer X99 chipset. This makes it faster than other Haswell chips, but at higher cost. But all Hasswell chips are 22nm process with the Haswell architecture, so their raw computation ability scales with clock speed and cores only.

The non-E Haswell uses the LGA 1150 socket, can only use DDR3 memory, and uses the older Z87 chipset. This makes all the parts cheaper (but slower for some software). However, I doubt you'd be able to benchmark the difference in memory speed without special care.

All that said, the "Consider" option saves only about 17% over the "Suggested" option.

Storage

I put in 2 3TB drives for the "Consider" option because your main storage will be on SSD and the disk drives are for backup. But all drives are unreliable, so running the 2 3TB drives in a mirror (RAID-1) will guard against a single-drive failure -- using a 4TB drive without backup is just crazy, since it will fail within 2-4 years. For pure backup purposes, a pair of $50 1TB drives are more than sufficient (total of $100). For large storage purposes, I'd have other (more expensive) suggestions.

Motherboard

The x16 and x8 in the motherboard section shows how fast each slot is when more than one slot are used together. I couldn't find an Asus motherboard with x16/x16/x8, but that's only important if you run 3 GPUs with SLI. I stongly recommend only 1 (or 2, at most).

Conclusion

Yes, we can save money by building the machine from parts, and might even be able to do better using amazon and newegg specials. However, the savings is not more than a few hundred dollars and doesn't include any kind of waranty, or the triangular chassis (and all prices are a bit higher with sales tax, which I haven't included).

Other options for reducing price would be to look at GTX 970 GPUs, less memory (16GB should be ok for games, no?), and the pre-Haswell chips.
