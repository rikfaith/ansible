HSIM -- An Open Source Simulator for Amateur Nitrous Hybrid Rocket Motors

Injector Parameters
 
Injector Diameter

Injectors are modeled as orifices of known diameter.

If you are using a UC-valve hybrid then this is the inner diameter of the fill tube.

Number of Injectors

How many injectors? All injectors are assumed to have the same diameter and Cd.

Injector Cd

This parameter attempts to model how liquid nitrous flows through the injector. Unfortunately accurate modeling the flow of saturated nitrous through a hot injector is beyond the scope of this simulator. The approximation of a constant Cd is used instead of a more accurate physical model.

I've seen recommendations for a value in the range 0.25 to 0.40 for UC valve injector Cd. Our injectors are small holes drilled in brass fittings and appear to have a measured Cd value of 0.7.

The value of this parameter will change as a function of the flight tank temperature.
